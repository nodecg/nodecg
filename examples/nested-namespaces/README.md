# nested namespaces example

This namespace declares two child namespaces, and uses them to derive computed values for graphics.

## Run

- `pnpm dev`: Start the development server
- `pnpm build`: Build the project
- `pnpm start`: Start the production server

Post a message on http://localhost:3000/frontend/namespaces/show/dashboard.html and watch it on http://localhost:3000/frontend/namespaces/show/graphics.html
